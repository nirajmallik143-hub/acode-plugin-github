# Acode Plugin GitHub

> ⚠️ **IMPORTANT WARNING:**
This plugin requires the Git [SCM plugin](https://acode.app/plugin/acode.plugin.version.control.gitpro) to function. It utilizes the Git SCM API, such as remote source and Git authentication, to connect with GitHub, enabling work with remotes in GitHub repositories and providing features like remote source, publisher, and GitHub authentication.

## Features
This plugin provides the following GitHub-related features for Acode:

- `Publish to GitHub` command
- `Clone from GitHub` participant to the `Git: Clone` command
- Automatic credential handling for Git operations
- Publish local repositories to GitHub directly from Acode
- Choose between creating public or private repositories
- Automatic fork creation when attempting to push to a repository without permissions
